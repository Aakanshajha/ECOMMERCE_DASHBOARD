# 🛒 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

The **E-Commerce Sales Dashboard** is an interactive data visualization and business intelligence project developed using Microsoft Power BI. The project focuses on analyzing e-commerce sales data to understand business performance, track revenue and profit, and identify important sales trends.

The dashboard transforms raw sales and order data into meaningful visual insights that help businesses monitor performance and make data-driven decisions.

## 📸 Dashboard Preview

![E-Commerce Dashboard](Screenshot%202026-11-04%20181319.png)


## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Track total revenue, profit, quantity, and orders.
- Identify top-performing product categories and sub-categories.
- Analyze customer purchasing behavior.
- Understand sales distribution across different states and cities.
- Compare different payment methods.
- Identify business trends and opportunities for improvement.

## ✨ Key Features

- **Sales Analysis:** Monitor sales performance and revenue.
- **Profit Analysis:** Understand profit contribution and profitability.
- **Category Analysis:** Compare product categories and sub-categories.
- **Customer Analysis:** Explore customer purchasing patterns.
- **Geographical Analysis:** Analyze sales across different states and cities.
- **Payment Analysis:** Understand customer payment preferences.
- **Interactive Dashboard:** Explore insights through visualizations and filters.

## 🛠️ Technologies Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- CSV Dataset
- Data Cleaning and Transformation

## 📂 Dataset Information

The project uses two CSV datasets:

**1. Details (1).csv**
- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- Payment Mode

**2. Orders.csv**
- Order ID
- Order Date
- Customer Name
- State
- City

These datasets provide information about sales transactions, products, customers, locations, and payment methods.

## 📊 Dashboard Insights

The dashboard helps explore the following business questions:

1. What is the overall sales and profit performance?
2. Which product categories generate more revenue?
3. Which sub-categories contribute the most to sales?
4. Which cities and states have higher sales?
5. Which payment methods are most commonly used?
6. How do sales and profits change over time?
7. Which areas offer opportunities for business growth?

## ⚙️ Project Workflow

1. Collected and imported e-commerce sales datasets.
2. Cleaned and transformed data using Power Query.
3. Created relationships between datasets using Order ID.
4. Developed calculated measures using DAX.
5. Designed interactive visualizations in Power BI.
6. Analyzed sales, profit, customers, products, and geographical performance.
7. Created a dashboard to present meaningful business insights.
